# PriorityLane

**Where clarity meets momentum.**

PriorityLane is a modern, full-stack task management application designed to help individuals and teams organize their work, focus on what matters most, and build momentum towards their goals. It features a clean, intuitive interface, real-time collaboration, and intelligent prioritization powered by AI.

## Key Features

*   **Intuitive Task Management**: Create, edit, and manage tasks and subtasks with ease through a beautiful, card-based interface.
*   **Drag-and-Drop Reordering**: Manually adjust your task order on the fly with a smooth drag-and-drop system.
*   **AI-Powered Prioritization**: Leverage the power of generative AI to analyze your active tasks and automatically suggest a priority order based on deadlines, impact, and other factors.
*   **Customizable Divisions**: Organize tasks into custom divisions or departments (e.g., "Operations," "Marketing," "Personal") to fit your unique workflow.
*   **Real-time & Secure**: Built on Firebase, all data is synchronized in real-time across devices. Authentication and security rules ensure that users can only access their own information.
*   **Rich Task Details**: Track deadlines, impact levels, owners, progress, and start/completion times for both tasks and subtasks.
*   **Responsive Design**: A fully responsive layout with a collapsible sidebar ensures a great experience on any device, from a large desktop monitor to a mobile phone.

## Technology Stack

*   **Frontend**: Next.js (App Router), React, TypeScript, Tailwind CSS
*   **UI Components**: ShadCN UI for a modern and accessible component library
*   **Backend**: Firebase (Authentication and Firestore Database)
*   **Artificial Intelligence**: Google's Genkit for the intelligent task prioritization flow
*   **State Management**: Custom React hooks for clean, centralized state management
*   **Deployment**: Ready for free, zero-config deployment on Vercel
